# Tapetum Sentinel

> حالة الترجمة: مسودة بمساعدة الذكاء الاصطناعي، بانتظار مراجعة لغوية بشرية.

[English](README.md) · [Türkçe](README.tr.md) · [Deutsch](README.de.md) · [العربية](README.ar.md)

Tapetum Sentinel منصة مفتوحة المصدر لتحليل الفيديو متمحورة حول الإنسان، مصممة لصور الطائرات المسيّرة والعمل الميداني. تحسن المدخلات البصرية وتكشف الأجسام حسب المهمة وتحفظ بيانات وصفية غنية بالأدلة وتتيح الإجابة محلياً دون اتصال عن الفيديو المحلل.

## المبادئ الأساسية

- التحول المتمحور حول الإنسان
- المصدر المفتوح افتراضياً
- التشغيل المحلي أولاً وإمكانية العمل دون اتصال
- معمارية مستقلة عن النموذج
- إجابات تستند إلى أدلة
- تحسين مستمر بناء على تغذية راجعة متحققة

## مسار المعالجة

```text
Video / Drone Feed
        |
        v
Retinex Tapetum Enhancement
        |
        v
Task-Specific YOLO Detection
        |
        v
Tracking + Metadata Fusion
        |
        v
Local Database + Evidence Index
        |
        v
Local LLM / RAG Question Answering
```

## بنية المستودع

- `apps/`: تطبيقات سطح المكتب وواجهات API
- `services/`: التحسين والكشف والتتبع والمعرفة وخدمات LLM المحلية
- `training/`: تدريب وتقييم عبر Colab
- `feedback/`: الوسم والتحقق وتصدير مجموعات البيانات
- `model-registry/`: ربط مهام المستخدم بالنماذج
- `database/`: مخططات وترحيلات
- `docker/`: موارد Docker
- `docs/`: المعمارية وسجلات القرارات
